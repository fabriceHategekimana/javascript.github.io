# Projet 3: Jeu de Memory (90 points)

**Description du projet :**

L'objectif de ce projet est de créer un jeu de Memory classique en utilisant JavaScript, HTML et CSS. Le joueur devra cliquer sur des cartes pour les retourner et trouver des paires correspondantes. Ce projet met l'accent sur la manipulation avancée du DOM, la gestion des événements utilisateur, et l'utilisation des outils de développement du navigateur pour le débogage.

**Instructions de développement :**

Le projet sera découpé en modules pour gérer la logique du jeu, l'interface utilisateur et la configuration.

**Partie 1: Structure et Style de Base**

1.  **Créer un fichier `index.html`**. Ce fichier contiendra la structure de base du jeu : une grille pour les cartes et potentiellement une zone pour afficher des informations (nombre de tentatives, score).
2.  **Créer un fichier `style.css`**. Définissez les styles pour le plateau de jeu, les cartes (recto et verso), et les animations de retournement.
    *   Prévoyez une classe CSS pour l'état "retourné" de la carte et une autre pour l'état "trouvé".

**Partie 2: Logique du Jeu**

1.  **Créer un fichier `Jeu.js`**. Ce module contiendra la logique principale du jeu, indépendamment de l'affichage.
2.  **Définir une classe `Jeu`**.
    *   Le constructeur pourrait prendre en paramètre un ensemble de symboles ou d'images pour les cartes.
    *   Il doit créer les paires, mélanger les cartes et initialiser l'état du jeu (cartes retournées, tentatives, etc.).
3.  **Implémenter les méthodes de jeu** :
    *   `selectionnerCarte(index)` : Gère la logique lorsqu'un joueur clique sur une carte. Cette méthode doit :
        *   Vérifier si la carte peut être retournée.
        *   Mémoriser la première et la seconde carte sélectionnée.
        *   Comparer les deux cartes sélectionnées.
        *   Mettre à jour l'état du jeu si une paire est trouvée.
        *   Réinitialiser les cartes si ce n'est pas une paire après un court délai.
    *   `estTermine()` : Vérifie si toutes les paires ont été trouvées.
4.  **Documentation** : Documentez la classe `Jeu` et ses méthodes avec JSDoc.
5.  **Tests** : Créez un fichier `Jeu.test.js`.
    *   Testez l'initialisation du jeu (mélange, état initial).
    *   Testez la logique de sélection : retourner une carte, trouver une paire, ne pas trouver de paire.
    *   Testez la condition de fin de jeu.

**Partie 3: Affichage et Interactions (UI)**

1.  **Créer un fichier `ui.js`**. Ce module sera responsable de la synchronisation entre l'état du jeu et le DOM.
2.  **Implémenter une fonction `creerGrille(jeu)`**. Cette fonction génère dynamiquement les éléments `div` des cartes dans le DOM en fonction de l'état initial du jeu. Chaque carte doit avoir un attribut (ex: `data-index`) pour l'identifier.
3.  **Implémenter une fonction `mettreAJourAffichage(jeu)`**. Cette fonction met à jour les classes CSS des cartes en fonction de leur état dans l'instance `Jeu` (retournée, trouvée, etc.).
4.  **Documentation** : Documentez les fonctions de ce module.

**Partie 4: Application Principale et Débogage**

1.  **Créer un fichier `main.js`**. Ce fichier initialise et connecte tous les modules.
2.  **Initialiser le jeu** :
    *   Créez une instance de la classe `Jeu`.
    *   Appelez `creerGrille` pour construire l'interface.
3.  **Gérer les événements** :
    *   Ajoutez un écouteur d'événements à la grille de jeu.
    *   Lorsqu'un clic est détecté sur une carte, récupérez son index et appelez `selectionnerCarte` sur l'instance du jeu.
    *   Après chaque sélection, appelez `mettreAJourAffichage` pour refléter les changements.
4.  **Utilisation des DevTools** :
    *   Utilisez `console.log` pour suivre l'état interne de votre instance `Jeu` à chaque tour.
    *   Placez des points d'arrêt (breakpoints) dans la méthode `selectionnerCarte` pour inspecter pas à pas la logique de comparaison.
    *   Inspectez les éléments du DOM pour vérifier que les classes CSS sont appliquées correctement.

Ce projet vous donnera une expérience pratique de la création d'une application interactive et de l'importance des outils de débogage.
