# Projet 8: Jeu du Pendu (90 points)

**Description du projet :**

L'objectif est de recréer le célèbre jeu du Pendu en JavaScript. Le jeu choisira un mot au hasard, et le joueur devra deviner les lettres qui le composent avant de manquer de tentatives. Ce projet se concentrera sur la programmation orientée objet (en utilisant des prototypes ou des classes ES6), la manipulation du DOM pour refléter l'état du jeu, et l'utilisation des outils de développement pour suivre la logique interne du jeu.

**Instructions de développement :**

La structure du projet séparera la logique du jeu de l'interface utilisateur.

**Partie 1: Modèles de Données et Logique du Jeu**

1.  **Créer un fichier `JeuPendu.js`**. Ce fichier contiendra la classe principale qui gère l'état et les règles du jeu.
2.  **Définir une classe `JeuPendu`**.
    *   Le constructeur prendra en paramètre le mot à deviner et le nombre de tentatives autorisées.
    *   Il initialisera l'état du jeu : le mot secret, les lettres déjà devinées (un tableau ou un `Set`), le nombre de tentatives restantes, et l'état d'avancement du mot affiché à l'utilisateur (ex: `_ _ _ _`).
3.  **Implémenter les méthodes de jeu** :
    *   `proposerLettre(lettre)`: La méthode centrale. Elle doit :
        *   Vérifier si la lettre a déjà été proposée.
        *   Ajouter la lettre aux lettres proposées.
        *   Si la lettre n'est pas dans le mot, décrémenter le nombre de tentatives.
        *   Mettre à jour l'état du mot affiché.
        *   Retourner un statut (ex: 'lettre trouvée', 'lettre non trouvée', 'déjà proposée').
    *   `getEtatMot()`: Retourne le mot avec les lettres devinées et des tirets pour les autres (ex: `P _ N D _`).
    *   `estGagne()`: Retourne `true` si toutes les lettres ont été trouvées.
    *   `estPerdu()`: Retourne `true` si le nombre de tentatives est tombé à zéro.
4.  **Documentation** : Documentez la classe et ses méthodes avec JSDoc.
5.  **Tests** : Créez `JeuPendu.test.js`.
    *   Testez l'initialisation du jeu.
    *   Testez la proposition d'une lettre : cas où elle est dans le mot, cas où elle n'y est pas, cas où elle a déjà été proposée.
    *   Testez les conditions de victoire et de défaite.

**Partie 2: Interface Utilisateur**

1.  **Créer `index.html`** avec les éléments nécessaires : une zone pour afficher le mot masqué, une autre pour les lettres déjà proposées, une section pour le nombre de tentatives restantes (ou pour dessiner le pendu), et un clavier virtuel (ou un simple champ de saisie) pour que l'utilisateur propose une lettre.
2.  **Créer `ui.js`**.
    *   `mettreAJourAffichage(jeu)`: Cette fonction met à jour tous les éléments de l'interface (le mot, les tentatives, les lettres proposées) en se basant sur l'état de l'instance `JeuPendu`.
    *   `afficherMessageFin(message)`: Affiche un message de victoire ou de défaite.
    *   `dessinerPendu(tentativesRestantes, totalTentatives)`: Met à jour l'image ou le dessin du pendu.

**Partie 3: Application Principale et Débogage**

1.  **Créer `main.js`**.
2.  **Liste de mots** : Définissez un tableau de mots à deviner.
3.  **Initialisation** :
    *   Choisissez un mot au hasard dans la liste.
    *   Créez une instance de `JeuPendu` avec ce mot.
    *   Appelez `ui.mettreAJourAffichage` pour afficher l'état initial.
4.  **Gestion des entrées utilisateur** :
    *   Ajoutez des écouteurs d'événements (sur le clavier virtuel ou un `input`).
    *   À chaque proposition de lettre par l'utilisateur :
        *   Appelez `jeu.proposerLettre()`.
        *   Mettez à jour l'affichage avec `ui.mettreAJourAffichage()`.
        *   Vérifiez si le jeu est gagné ou perdu. Si c'est le cas, affichez le message final et désactivez les entrées.
5.  **Utilisation des DevTools** :
    *   Utilisez `console.log(jeu)` après chaque proposition de lettre pour voir l'objet `JeuPendu` complet et suivre l'évolution de son état (lettres proposées, tentatives restantes, etc.).
    *   Placez un point d'arrêt dans `proposerLettre` pour inspecter la logique pas à pas quand vous testez une nouvelle lettre.

Ce projet est excellent pour pratiquer la conception orientée objet et la gestion d'état dans une application interactive.
