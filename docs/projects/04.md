# Projet 4: Gestionnaire de Tâches (Todo-List) (60 points)

**Description du projet :**

L'objectif est de construire une application de type "Todo-List" qui permet aux utilisateurs d'ajouter, de consulter et de supprimer des tâches. Pour assurer la persistance des données entre les sessions, les tâches seront sauvegardées dans le `localStorage` du navigateur. Le projet sera structuré en modules ES6 pour bien séparer la logique de gestion des données, la manipulation de l'interface utilisateur et la coordination générale de l'application.

**Instructions de développement :**

Le projet est divisé en trois modules principaux, chacun ayant un rôle bien défini.

**Partie 1: Service de Persistance des Tâches**

1.  **Créer un fichier `taskService.js`**. Ce module sera une couche d'abstraction responsable de toutes les interactions avec le `localStorage`.
2.  **Implémenter les fonctions de gestion** :
    *   `getTasks()`: Cette fonction doit lire la liste des tâches depuis le `localStorage`. Si aucune tâche n'est présente, elle doit retourner un tableau vide. N'oubliez pas de désérialiser les données (par exemple, avec `JSON.parse`).
    *   `saveTasks(tasks)`: Cette fonction prend un tableau de tâches et le sauvegarde dans le `localStorage`. Vous devrez sérialiser le tableau (par exemple, avec `JSON.stringify`).
    *   `addTask(task)`: Ajoute une nouvelle tâche à la liste existante dans le `localStorage`.
    *   `deleteTask(taskId)`: Supprime une tâche de la liste en se basant sur un identifiant unique.
3.  **Documentation** : Documentez chaque fonction avec JSDoc pour expliquer son rôle et comment elle interagit avec le `localStorage`.
4.  **Tests** : Créez un fichier `taskService.test.js`.
    *   Pour tester ce module, vous pouvez simuler l'API `localStorage`.
    *   Testez que `getTasks` retourne bien un tableau vide au début.
    *   Testez que `saveTasks` et `getTasks` fonctionnent en tandem.
    *   Testez l'ajout et la suppression de tâches, en vérifiant l'état du `localStorage` simulé.

**Partie 2: Module d'Interface Utilisateur (UI)**

1.  **Créer un fichier `ui.js`**. Ce module gérera l'affichage et les interactions purement visuelles.
2.  **Créer `index.html`** avec la structure nécessaire : un formulaire pour ajouter une tâche, une liste (`<ul>` ou `<div>`) pour afficher les tâches et un bouton de suppression pour chaque tâche.
3.  **Implémenter les fonctions d'affichage** :
    *   `renderTasks(tasks)`: Prend un tableau de tâches et génère le HTML correspondant pour les afficher dans la liste. Chaque élément de la liste doit inclure le texte de la tâche et un bouton de suppression avec un identifiant unique (par exemple, `data-id`).
    *   `clearInput()`: Vide le champ de saisie du formulaire après l'ajout d'une tâche.
4.  **Documentation** : Documentez les fonctions pour clarifier leur rôle dans la manipulation du DOM.
5.  **Tests** : Les tests pour ce module peuvent être manuels. Vérifiez que la liste des tâches s'affiche correctement et que le champ de saisie est bien vidé.

**Partie 3: Logique Applicative Principale**

1.  **Créer un fichier `main.js`**. Ce fichier est le chef d'orchestre qui connecte le service de données et l'interface utilisateur.
2.  **Importer les modules** `taskService.js` et `ui.js`.
3.  **Initialiser l'application** :
    *   Au chargement de la page, appelez `taskService.getTasks()` pour récupérer les tâches.
    *   Puis, appelez `ui.renderTasks()` avec les tâches récupérées pour afficher la liste initiale.
4.  **Gérer l'ajout de tâches** :
    *   Ajoutez un écouteur d'événement sur la soumission du formulaire.
    *   Quand le formulaire est soumis, empêchez le comportement par défaut, récupérez le texte de la nouvelle tâche, créez un objet tâche (avec un `id` unique et le `texte`), appelez `taskService.addTask()`, puis mettez à jour l'affichage en récupérant la nouvelle liste et en appelant `ui.renderTasks()`.
5.  **Gérer la suppression de tâches** :
    *   Ajoutez un écouteur d'événement sur la liste des tâches (délégation d'événements).
    *   Si le clic provient d'un bouton de suppression, récupérez l'identifiant de la tâche, appelez `taskService.deleteTask()`, puis mettez à jour l'affichage de la même manière que pour l'ajout.

Cette approche modulaire rendra votre code plus propre, plus facile à maintenir et à tester.
