# Projet 6: Visualiseur de Données (90 points)

**Description du projet :**

L'objectif est de créer une application web capable de récupérer un ensemble de données depuis une API publique (comme JSONPlaceholder) et de les afficher de manière structurée et visuelle. Les données seront présentées dans un tableau triable et sous forme de graphique à l'aide d'une bibliothèque comme Chart.js. Ce projet se concentre sur la récupération de données asynchrones, leur traitement et leur représentation visuelle, ainsi que sur l'analyse des performances réseau avec les outils de développement du navigateur.

**Instructions de développement :**

Le projet sera organisé en modules pour la récupération des données, leur affichage tabulaire et leur visualisation graphique.

**Partie 1: Service de Données**

1.  **Créer un fichier `apiService.js`**. Ce module centralisera tous les appels à l'API externe.
2.  **Implémenter une fonction `fetchData(endpoint)`**.
    *   Cette fonction sera asynchrone (`async/await`) et utilisera `fetch` pour interroger une URL d'API (par exemple, `https://jsonplaceholder.typicode.com/users`).
    *   Elle doit gérer les succès en retournant les données JSON et les erreurs réseau en levant une exception.
3.  **Documentation** : Documentez la fonction avec JSDoc, en précisant le paramètre `endpoint` et le type de données retournées.
4.  **Tests** : Créez `apiService.test.js`. Simulez `fetch` pour tester la récupération de données en cas de succès et la gestion d'erreur en cas d'échec de l'appel réseau.

**Partie 2: Affichage Tabulaire**

1.  **Créer un fichier `dataTable.js`**. Ce module sera responsable de la création et de la gestion du tableau de données.
2.  **Créer `index.html`** avec un conteneur (`<div>`) pour le tableau et un autre pour le graphique.
3.  **Implémenter une fonction `createTable(headers, data)`**.
    *   Cette fonction génère dynamiquement un tableau HTML (`<table>`) à partir d'un tableau d'en-têtes et d'un tableau d'objets de données.
    *   Les en-têtes du tableau doivent être cliquables pour permettre le tri.
4.  **Implémenter une logique de tri**.
    *   Ajoutez des écouteurs d'événements sur les en-têtes.
    *   Lors d'un clic, triez le tableau de données en fonction de la colonne correspondante et régénérez le tableau avec les données triées.
5.  **Documentation** : Documentez la fonction de création du tableau.
6.  **Tests** : Testez manuellement que le tableau s'affiche correctement et que le tri fonctionne pour différentes colonnes (alphabétique, numérique).

**Partie 3: Visualisation Graphique**

1.  **Inclure Chart.js** dans votre projet. Vous pouvez le faire via une balise `<script>` dans votre `index.html` pointant vers un CDN.
2.  **Créer un fichier `dataChart.js`**.
3.  **Implémenter une fonction `createChart(data)`**.
    *   Cette fonction doit d'abord traiter les données brutes pour les transformer dans un format accepté par Chart.js (par exemple, compter le nombre d'utilisateurs par ville).
    *   Ensuite, elle doit instancier un nouveau graphique (ex: un diagramme à barres) sur l'élément `<canvas>` que vous aurez ajouté dans votre `index.html`.
4.  **Documentation** : Documentez la fonction en expliquant le type de données attendu et le type de graphique généré.

**Partie 4: Application Principale et Analyse**

1.  **Créer un fichier `main.js`**.
2.  **Coordonner les modules** :
    *   Utilisez `async/await` dans un bloc `try...catch` pour appeler `apiService.fetchData`.
    *   En cas de succès, passez les données à `dataTable.createTable` et à `dataChart.createChart`.
    *   En cas d'erreur, affichez un message clair à l'utilisateur.
3.  **Utilisation des DevTools** :
    *   Ouvrez l'onglet "Network" (Réseau) pour inspecter la requête `fetch`. Vérifiez le statut, le temps de réponse et la taille des données transférées.
    *   Utilisez l'onglet "Performance" pour analyser le temps de rendu de la page, en particulier après le chargement des données et la génération du tableau et du graphique. Identifiez les éventuels goulots d'étranglement.

Ce projet vous apprendra à gérer un flux de données complet, de la récupération à la présentation sous différentes formes.
