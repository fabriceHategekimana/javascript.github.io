# Projet 1: Mini-Météo (30 points)

**Description du projet :**

L'objectif de ce projet est de créer une application web simple qui affiche les conditions météorologiques actuelles pour une ville donnée. L'application interrogera une API météo publique pour obtenir les données et mettra à jour dynamiquement l'interface utilisateur pour afficher des informations telles que la température, l'humidité et une description du temps. Ce projet mettra l'accent sur la programmation asynchrone en JavaScript moderne (ES6+), la manipulation du DOM et la gestion des erreurs.

**Instructions de développement :**

Le projet sera divisé en plusieurs modules indépendants, chacun avec ses propres responsabilités, tests et documentation.

**Partie 1: Service Météo (API)**

1.  **Créer un fichier `weatherService.js`**. Ce module sera responsable de toute la communication avec l'API météo (par exemple, OpenWeatherMap).
2.  **Implémenter une fonction `getWeather(city)`**. Cette fonction prendra un nom de ville en paramètre.
    *   Elle utilisera `fetch` pour envoyer une requête à l'API météo.
    *   Elle doit utiliser `async/await` pour gérer la nature asynchrone de la requête.
    *   Elle doit gérer les réponses réussies en retournant les données météo au format JSON.
    *   Elle doit également gérer les erreurs (par exemple, ville non trouvée, problème de réseau) en levant une exception ou en retournant une erreur explicite.
3.  **Documentation** : Documentez la fonction `getWeather` avec JSDoc, en expliquant son but, ses paramètres et ce qu'elle retourne (y compris les cas d'erreur).
4.  **Tests** : Créez un fichier `weatherService.test.js`. Pour tester ce module, vous pouvez simuler (ou "mocker") l'API `fetch` afin d'éviter de faire de vrais appels réseau.
    *   Testez le cas où une ville valide est fournie et que les données sont retournées correctement.
    *   Testez le cas où une ville invalide est fournie et qu'une erreur est gérée.

**Partie 2: Interface Utilisateur (DOM)**

1.  **Créer un fichier `ui.js`**. Ce module sera responsable de toute manipulation du DOM.
2.  **Créer un fichier `index.html`** avec la structure de base : un champ de saisie pour le nom de la ville, un bouton de recherche et une section dédiée à l'affichage des résultats.
3.  **Implémenter une fonction `displayWeather(data)`** dans `ui.js`. Cette fonction prendra un objet de données météo et mettra à jour le DOM pour afficher les informations de manière claire.
4.  **Implémenter une fonction `displayError(message)`** dans `ui.js` pour afficher un message d'erreur à l'utilisateur dans la section des résultats.
5.  **Documentation** : Documentez les fonctions de manipulation du DOM avec JSDoc.
6.  **Tests** : Les tests de l'interface utilisateur peuvent être effectués manuellement. Assurez-vous que l'affichage est correct pour différentes données et que les messages d'erreur s'affichent comme prévu.

**Partie 3: Logique Applicative (main)**

1.  **Créer un fichier `main.js`**. Ce fichier agira comme le point d'entrée et le coordinateur de l'application.
2.  **Importer les modules** `weatherService.js` et `ui.js`.
3.  **Ajouter un écouteur d'événements** au formulaire de recherche.
4.  Lors de la soumission du formulaire :
    *   Récupérez la ville depuis le champ de saisie.
    *   Utilisez un bloc `try...catch` pour appeler la fonction `getWeather` du service météo.
    *   Si l'appel réussit, passez les données à `displayWeather` du module UI.
    *   Si une erreur est capturée, passez le message d'erreur à `displayError` du module UI.

En suivant ces étapes, vous construirez une application modulaire, maintenable et conforme aux meilleures pratiques JavaScript modernes.
